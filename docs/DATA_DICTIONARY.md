
# Happy Farm - Data Dictionary

This document describes the datasets used in the
Happy Farm project and their relevance to agricultural
decision-making.

## 1. NASA POWER - Climate Data

**Source:** NASA POWER

**Purpose:** Provides meteorological data for
understanding climate conditions in agricultural regions.

| Variable | Meaning | Unit |
|---|---|---|
| T2M | Temperature at 2 meters | °C |
| PRECTOTCORR | Corrected precipitation | mm/day |
| RH2M | Relative humidity at 2 meters | % |
| WS2M | Wind speed at 2 meters | m/s |
| ALLSKY_SFC_SW_DWN | Downward shortwave solar radiation | kWh/m²/day |

**Agricultural relevance:**
Used to analyze temperature, rainfall, humidity,
and solar radiation patterns that affect crop suitability.

## 2. MODIS - Satellite Data

**Source:** NASA MODIS

**Purpose:** Provides satellite observations of the
Earth's surface.

**Downloaded region:** Mansoura, Egypt

**Period:** January 2024 - December 2024

**Product:** To be documented based on the actual
MODIS product selected.

**Variables and bands:**
To be documented after inspecting the downloaded product.

**Agricultural relevance:**
Can support vegetation monitoring and analysis of
land surface conditions, depending on the selected product.

## 3. SoilGrids - Soil Data

**Source:** ISRIC SoilGrids

**Purpose:** Provides global soil property information.

**Variables:**
To be documented according to the selected SoilGrids layers.

**Agricultural relevance:**
Helps characterize soil properties that influence
crop suitability and agricultural planning.

## 4. Agricultural Reference Data

**Source:** To be documented.

**Purpose:** Contains crop-related information such as
crop requirements, growing seasons, and rotation constraints.

**Agricultural relevance:**
Used to connect environmental conditions with
agricultural recommendations.
